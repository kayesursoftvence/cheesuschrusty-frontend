1. System Architecture Overview

Core Concept: Database-Driven Configuration

The system has three layers of configuration. All UI components read from these tables to determine what options to display.

LayerWhat It ControlsWho Controls It
Global Config Which languages and levels are available to all users Admin via Product Configuration
User Override Grant specific users access to non-public languages/levels (beta testing, VIPs) Admin via User Management
User Profile User's selected language, level, and preferences User via Settings (within allowed options)

Access Logic

User can access a language/level IF:
  (language_level_config.is_active = true)   -- Globally enabled
  OR
  (user_access_override record exists)       -- Admin granted override

Query: Get Available Levels for User

SELECT llc.level, lc.display_name, lc.description
FROM language_level_config llc
JOIN level_config lc ON llc.level = lc.level
WHERE llc.language = {user.target_language}
  AND (
    llc.is_active = true
    OR EXISTS (
      SELECT 1 FROM user_access_override uao
      WHERE uao.user_id = {user.id}
        AND uao.language = llc.language
        AND uao.level = llc.level
    )
  )
ORDER BY lc.display_order;

Code Example: Populating Feedback Variables

async function evaluateFeedback(taskInstanceId, studentResponse, userId) {
  // 1. Load user profile
  const user = await db.query(`
    SELECT current_level, target_language, primary_language 
    FROM users WHERE id = $1
  `, [userId]);
  
  // 2. Get flag emoji from language_config
  const langConfig = await db.query(`
    SELECT flag_emoji FROM language_config WHERE language = $1
  `, [user.rows[0].target_language]);
  
  // 3. Load the task that was originally generated
  const task = await db.query(`
    SELECT content FROM task_instances WHERE id = $1
  `, [taskInstanceId]);
  const taskData = task.rows[0].content;
  
  // 4. Extract context and keys based on task type
  let context, answerKey, modelAnswer;
  const taskId = taskData.meta.task_id;
  
  if (taskId.startsWith('L') || taskId.startsWith('R')) {
    // OBJECTIVE TASKS: Need answer key
    context = JSON.stringify(taskData.student_handout);
    answerKey = taskData.teacher_pack.answer_key
      .map((item, idx) => `${idx + 1}-${item.correct}`)
      .join('\n');
    modelAnswer = 'N/A';
  } else {
    // SUBJECTIVE TASKS: Need model answer
    context = taskData.student_handout.stimulus.prompt;
    answerKey = 'N/A';
    modelAnswer = taskData.teacher_pack.model_answer;
  }
  
  // 5. Derive SKILL from TASK_ID
  const skillMap = { 'L': 'Listening', 'R': 'Reading', 'W': 'Writing', 'S': 'Speaking' };
  const skill = skillMap[taskId.charAt(0)];
  
  // 6. Load prompt template and replace all placeholders
  const promptTemplate = await getProductionPrompt('feedback_evaluator');
  
  const prompt = promptTemplate
    .replaceAll('{LEVEL}', user.rows[0].current_level)
    .replaceAll('{TARGET_LANGUAGE}', user.rows[0].target_language)
    .replaceAll('{PRIMARY_LANGUAGE}', user.rows[0].primary_language)
    .replaceAll('{TARGET_FLAG}', langConfig.rows[0].flag_emoji)
    .replaceAll('{TASK_ID}', taskId)
    .replaceAll('{SKILL}', skill)
    .replaceAll('{CONTEXT}', context)
    .replaceAll('{ANSWER_KEY}', answerKey)
    .replaceAll('{MODEL_ANSWER}', modelAnswer)
    .replaceAll('{STUDENT_RESPONSE}', studentResponse)
    .replaceAll('{WORD_COUNT}', studentResponse.split(/\s+/).length.toString());
  
  // 7. Send to AI
  return await callAI(prompt);
}
